# Swiggy Data Analysis Dashboard - Excel

## Project Overview
This project is an interactive Swiggy Sales and Customer Data Analysis Dashboard created using Microsoft Excel.

The dashboard helps analyze:
- Sales performance
- Customer behavior
- Order trends
- Profit analysis
- Food category performance

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Cleaning
- Dashboard Design

---

## Features
- Interactive dashboard with slicers
- Monthly sales trend analysis
- Top-performing categories
- Profit and revenue insights
- Customer order analysis
- Dynamic charts and visualizations

---

## Dashboard Insights
Some key insights from the dashboard:
- Total sales and profit performance
- Most ordered food categories
- Monthly growth trends
- Customer purchasing patterns
